# Publicação no GitHub pelo navegador — Windows

## 1. Criar o repositório

1. Entre na conta `ProfRenatoMedeirosFisico`.
2. Clique em **New repository**.
3. Nome: `qmap-cpmd-analysis`.
4. Descrição sugerida:
   `Analysis scripts and processed data for the QMAP-DMSO Car-Parrinello molecular dynamics study.`
5. Selecione **Public**.
6. Não marque a criação automática de README, `.gitignore` ou licença, pois este pacote já contém esses arquivos.
7. Clique em **Create repository**.

## 2. Enviar o pacote

No repositório vazio:

1. Clique em **uploading an existing file**.
2. Abra a pasta descompactada `qmap-cpmd-analysis`.
3. Arraste todos os arquivos e pastas para a área de upload.
4. Mensagem do commit:
   `Initialize reproducibility repository`
5. Clique em **Commit changes**.

Para muitos arquivos, subpastas profundas ou arquivos grandes, é mais seguro usar GitHub Desktop ou Git pela linha de comando.

## 3. Não tornar a resposta ao revisor definitiva ainda

Antes de inserir a URL no manuscrito:

1. complete `REPOSITORY_COMPLETION_CHECKLIST.md`;
2. confirme a composição real do sistema;
3. adicione todos os scripts Python e VMD realmente usados;
4. adicione as tabelas processadas das figuras;
5. gere uma release `v1.0.0`;
6. use a URL da release ou um DOI arquivado.
