# Suggested reviewer response after repository completion

**Reviewer comment 4:** To improve reproducibility, the Python scripts and VMD scripts used in the analysis should be made available in a public repository, e.g., GitHub, or an institutional repository.

**Response:** We agree with the reviewer. The Python and VMD scripts used for the structural, hydrogen-bond, dipole-moment, qualitative IR-like, and orientational-correlation analyses have been deposited in a public repository together with the processed numerical files required to reproduce the figures. The repository also contains dependency information, verified atom selections, execution instructions, and a figure-provenance table. The repository information has been added to the Methods and Data availability sections of the revised manuscript (p. 4, Section 2; p. 18, Data availability).

Repository: https://github.com/ProfRenatoMedeirosFisico/qmap-cpmd-analysis
